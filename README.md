# Python Number Guessing Game

A simple, interactive number guessing game built with Python. Test your luck and logical thinking by trying to guess the secret number selected by the computer!

## About the Project

The **Number Guessing Game** is a beginner-friendly Python project that demonstrates fundamental programming concepts, including random number generation, conditional statements, loops, and user input.

The computer randomly selects a number, and the player attempts to guess it. After each guess, the game provides feedback to help the player figure out whether the secret number is higher or lower.

## Features

- **Random Number Generation** — The computer generates a secret number randomly.
- **Instant Feedback** — Get hints indicating whether your guess is too high or too low.
- **Interactive Gameplay** — Keep guessing until you find the correct number.
- **Win Condition** — Receive a congratulatory message when you guess correctly.
- **Pure Python** — Built using Python's standard library, with no external dependencies.
- **Difficulty Levels** — Choose between Easy, Medium, and Hard modes.

## Technologies Used

- **Language:** Python 3
- **Module:** `random`

## Getting Started

### Prerequisites

Make sure you have Python 3 installed on your computer.

Check your Python version using:

```bash
python --version
```

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/number-guessing-game.git
   ```

2. Navigate to the project directory:

   ```bash
   cd number-guessing-game
   ```

3. Run the game:

   ```bash
   python main.py
   ```

   If your system uses `python3`, run:

   ```bash
   python3 main.py
   ```

## How to Play

1. Launch the game in your terminal.
2. Choose your preferred difficulty level.
3. The computer generates a secret number.
4. Enter your guess when prompted.
5. Follow the hints to figure out the correct number.
6. Keep guessing until you win!
